# NumericalAnalysis
A calculator that can solve a variaty of equations, including finding the roots and matrix manipulation.(Using multiple methods)
No dependencies exist. Compile and run using the 'makefile'.
Note:   You might've noticed already that all of implementations are directly written inside the header files.
        That's obviously not the best practice but I did it to simplify the compilation.(No need to compile each .c implementation, just the main.c)
